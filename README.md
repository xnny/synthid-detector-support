For bug reports, include your extension version, Chrome version, operating system, steps to reproduce, and the expected and actual results. Screenshots and logs are optional.

## Before reporting

SynthID Detector is an independent third-party extension, not an official Google product. It checks images for Google's SynthID watermark through [synthid.com](https://synthid.com/).

- Sign in to synthid.com in the same Chrome profile before using the extension.
- Right-click an image to check it, or use the toolbar button / `Alt+Shift+D` to select an image or screen area. In selection mode, confirm before uploading.
- Selected images or confirmed cropped screenshots are uploaded to Google's synthid.com for detection. Only static screenshots of canvas or video content can be checked.
- A screenshot of a small or resized image may be less reliable than the image file.
- **No SynthID detected does not mean the image was not created with AI.**

See the [usage guide](https://synthid-detector.tto.me/how-to-use/) for instructions and limitations.
